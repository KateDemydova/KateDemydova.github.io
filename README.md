# React App — Контекст API

## Опис завдання

Мета завдання — реалізувати контекст у React для передачі глобальних даних без використання пропсів (prop drilling).

---

## Структура

- **`src/context/AppContext.tsx`** — створення контексту, провайдера та кастомного хука `useAppContext`.
- **`App.tsx`** — головний компонент, обгорнутий у `<AppProvider>`.
- **`ParentComponent → ChildComponent → GrandChildComponent`** — вкладені компоненти, які отримують дані з контексту.

---

## Функціонал

- Глобальний стан — список користувачів (`users`).
- Функція `addUser` дозволяє додавати нових користувачів.
- Компонент `GrandChildComponent`:
  - Виводить список користувачів.
  - Має поле введення для додавання нового користувача.

---

## Основні методи

✅ Контекст створено за допомогою `createContext`.  
✅ Провайдер (`AppProvider`) надає глобальні дані (список користувачів і функцію додавання).  
✅ Дані доступні у вкладених компонентах через кастомний хук `useAppContext` (на основі `useContext`).  
✅ Уникається прокидання пропсів між компонентами.

## Призначення

Цей приклад демонструє базову реалізацію React Context API для керування 
глобальним станом у простому проєкті без зовнішніх бібліотек (як-от Redux).
