# Маршрутизація в React з використанням React Router

## Опис проекту
Цей проект представляє собою багатосторінковий додаток, створений за допомогою
React і React Router. Цей додаток включає в себе:
-динамічну маршрутизацію;
-виділення активного пункту меню;
-можливість оновлення контенту без перезавантаження сторінки;
-сторінка 404 для неіснуючих маршрутів;
-можливість вкладеної навігації.


## Ініціалізація проекту
1. Клонуйте рипозиторії
git clone https://github.com/KateDemydova/KateDemydova.github.io.git

2. Перейдіть у каталог
   cd my-react-router-app

3. Встановіть залежності
npm install

4. Зберіть проект 
npm run build

5. Запустіть сервер
npm run dev
