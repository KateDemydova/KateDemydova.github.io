Gzip Compression & Decompression Utility
Цей модуль надає асинхронні функції для компресії та декомпресії файлів за допомогою алгоритму Gzip. Підходить для використання у Node.js (ESM) середовищі, підтримує стрімове API та забезпечує високу надійність.

📘 API
compressFile(filePath: string): Promise<string>
Компресує вхідний файл з використанням Gzip. Якщо файл з цільовим ім'ям вже існує — генерує унікальну назву.

Параметри:
filePath — шлях до існуючого файлу (наприклад, ./files/source.txt)

Повертає:
Шлях до нового .gz файлу

decompressFile(compressedFilePath: string, destinationFilePath: string): Promise<string>
Розпаковує Gzip-файл у заданий шлях. Якщо файл уже існує — створює унікальний.

Параметри:
compressedFilePath — шлях до .gz файлу

destinationFilePath — очікуваний шлях до розпакованого файлу

Повертає:
Шлях до нового розпакованого файлу
performCompressionAndDecompression(): Promise<void>
Функція для демонстрації та тестування — спочатку виконує компресію ./files/source.txt, а потім — декомпресію отриманого .gz файлу.
Тестування
Модуль готовий до мокування та тестування через Jest. Наприклад, можна перевірити:

Успішну компресію/декомпресію

Обробку помилок (відсутність файлу, відсутність доступу)

Створення унікального імені при конфліктах

⚠️ Обробка помилок
У випадку помилок (наприклад, файл не існує), функції кидають виключення з описом:
Error: file "./files/unknown.txt" does not exist

Ви можете обробити їх у try/catch.
