# ДЗ #1 Node.js

## Виконані завдання:
1. Розробка функції "isDebugMode" , що визначає режим відладки та логує значення у консоль.
2. Розробка функцій "encodeToBase64", "encodeToHex", "decodeFromBase64", і "decodeFromHex", 
що виконують кодування та декодування форматів base64 та Hex.
3. Розробка функцій "safeDecodeFromBase64" та "safeDecodeFromHex", що виконує
безпечне кодування та валідацію даних.
