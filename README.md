# Тестування асинхронного запиту з використанням Vitest

## Опис
Реалізовано асинхронний GET-запит до API (https://jsonplaceholder.typicode.com/users/1) 
для отримання даних користувача. Компонент обробляє і відображає три стани:

* індикатор завантаження під час запиту

* дані користувача після успішного отримання

* повідомлення про помилку у разі невдалого запиту

## Використані технології
* React — для побудови UI та керування станом компонента

* Vitest — для написання та запуску тестів

* @testing-library/react — для тестування поведінки React-компонентів

## Покриття тестами
Реалізовано тести для перевірки наступних сценаріїв:

* Відображення індикатора завантаження під час виконання запиту

* Відображення повідомлення про помилку, якщо запит не вдався

Для тестування використовувалось мокування API за допомогою vi.fn() з бібліотеки Vitest, 
що дозволяє ізолювати тести від реального зовнішнього сервісу.
