# CRM Клієнтська Система
Це CRM-застосунок на базі React + TypeScript для управління клієнтами. 
Дозволяє додавати, редагувати, фільтрувати клієнтів, а також відображає статуси, 
VIP-позначки та інформацію про оплату.

## Використані технології
React 18

TypeScript

React Router DOM

React Hook Form

TanStack React Query

Phone Input (react-phone-input-2)

Lucide Icons

## Основні функції
### Додавання нового клієнта
Форма включає поля:

Ім’я (обов’язкове, мін. 5 символів)

Email (обов’язковий, з перевіркою формату)

Телефон (обов’язковий, з маскою для +380 через react-phone-input-2)

Компанія (необов’язково)

Посада (необов’язково)

VIP-клієнт (чекбокс)

Статус: active, inactive, awaiting_payment, debtor

### Перевірка на дублікат:

Якщо клієнт з такою ж email-адресою вже існує — з’являється confirm() з повідомленням.

При скасуванні — дані не відправляються.

### Пошук клієнтів
Реалізовано у компоненті Sidebar

Пошук працює з першої літери імені

Нічого не відбувається при натисканні Enter (оскільки це не форма)

Якщо результатів немає — відображається повідомлення

### Редагування клієнта
Дані клієнта підтягуються через useParams()

Якщо ID некоректний або клієнта немає — показується повідомлення

Після збереження — перенаправлення на головну сторінку

### Сторінка оплат
Доступна за шляхом /payments

Виводить лише клієнтів зі статусом "awaiting_payment"

Формат дати — дд.мм.рррр (наприклад: 01.06.2025)

Сума до сплати та термін виводяться окремо.

## Бічне меню (Sidebar)

Кнопки переходу:

На головну

Додати нового клієнта

Список оплат

Інпут пошуку клієнтів

Активна сторінка підсвічується (active клас для NavLink)

## Валідація

Ім’я: мін. 5 символів, обов’язкове

Email: формат user@example.com

Телефон: мін. 12 цифр, +380 за замовчуванням

Усі перевірки реалізовано через react-hook-form.

Встановлення та запуск

# Встановлення залежностей
npm install

# Запуск проєкту
npm run dev

## Додатково
Всі поля стилізовані CSS-класами: input-item, button, label, form-group

Статуси автоматично переводяться на українську мову:

active           => Активний
inactive         => Неактивний
awaiting_payment => Очікує оплату
debtor           => Боржник
VIP клієнти позначаються жовтою зірочкою 🌟.
